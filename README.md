# AI Resume Analyzer

An AI-powered Resume Analyzer built with React, Flask, Groq AI, and PyPDF2.

## Features
- ATS Score
- Missing Skills Detection
- Resume Suggestions
- PDF Resume Upload
- Job Description Matching
- AI Powered Analysis

## Tech Stack
- React
- Flask
- Groq AI
- PyPDF2
- Python

## Installation

### Frontend
```bash
npm install
npm run dev
```

### Backend
```bash
pip install -r requirements.txt
python app.py
```
